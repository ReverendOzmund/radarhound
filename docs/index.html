Phone mode

No server at all

The same Radarhound page runs inside the app and fetches its own data.

  • Lightning, forecasts, satellite

Install

  1. Install Docker (Docker Desktop on Windows or macOS).
  2. Get Radarhound and start it: 
    git clone https://github.com/ReverendOzmund/radarhound.git
cd radarhound
docker compose up -d --build
  3. Open http://localhost:8686. The welcome tour asks how much detail you want and where home is. Set your local radars and state warnings feed in docker-compose.yml (see the README).
  4. Phone: open http://<your-server>:8686/app on Android, or grab the APK from Releases and choose "Run on this phone".

Ctrl+K: one search box for modes, layers, radars, settings and places.

Data and fine print

Unofficial. Radarhound's own warnings, watches and storm ratings come from a hobby algorithm and can be wrong, late or missing. Always follow the Bureau of Meteorology and emergency services.

Radarhound ships no weather data. Your own server or phone fetches it for your personal use from:

SourceUsed for
Bureau of MeteorologyRadar, warnings, observations, radar archive. Personal use; don't serve it to others.
Blitzortung.org / LightningMapsLightning. Private, non-commercial use.
Open-MeteoForecasts and forecast maps. Non-commercial free tier, CC BY 4.0.
NOAA, NASA GIBS and FIRMS, CIRA SLIDERSatellite and fire hotspots.
Aviation Weather Center, University of Wyoming, OpenStreetMap, GeoNames, Natural EarthAirport reports, soundings, address search, towns, borders.
